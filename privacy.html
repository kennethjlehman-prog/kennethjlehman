Privacy Policy

Last updated: October 26, 2026

ha-nest-app ("the app") is a private, personal-use application operated by its owner solely to connect the owner's own Home Assistant installation to the owner's own Google Nest devices. It is not offered to the public.

Information the app accesses

When the owner authorizes the app with their Google Account, the app receives OAuth access and refresh tokens and can access Google Nest device information and controls through the Google Smart Device Management API. This includes device names and status, temperature and mode settings, and camera or doorbell events, as permitted by the scopes the owner approves. The app does not access Gmail, Drive, Contacts, or any other Google service.

How information is used

This information is used only to display and control the owner's devices within their own Home Assistant installation.

Storage and sharing

Authorization tokens and device data are stored only within the owner's private Home Assistant installation. The app does not sell, share, transfer, or disclose this information to any third party, and does not use it for advertising or any purpose other than operating the owner's smart home.

Google API Services User Data Policy

The app's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Data retention

Tokens and device data are kept only for as long as the integration is installed in the owner's Home Assistant. Removing the integration or revoking access deletes them.

Revoking access and deleting data

Access can be revoked at any time from the Google Account permissions page (myaccount.google.com/permissions). Removing the integration from Home Assistant deletes the stored tokens and device data.

Security

Tokens are stored only on the owner's private Home Assistant server, which is protected by the owner's own access controls. They are never transmitted to any server operated by the app's author.

Website visitors

This website is a static page hosted on GitHub Pages. It has no forms, accounts, analytics, or advertising, and the app's author collects no information from visitors. GitHub may log standard web traffic under its own privacy statement.

Children

The app is not directed to children and is not offered to the public.

Changes to this policy

If this policy changes, the updated version will be posted on this page with a new "Last updated" date.
